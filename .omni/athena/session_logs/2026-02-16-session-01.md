## Summary

This session focused on hardening the AI Remote Control features, specifically addressing window targeting inaccuracies and monitor movement behaviors. We also improved the Android user experience by preventing screen timeout during fullscreen keyboard usage.

## Technical Details

### 1. Hardened Window Targeting (`ProcessService.cs`)
- **Strict Tree Resolution**: Updated `GetProcessTreePids` to more accurately link CLI processes to their host terminals. It now specifically checks for parent `WindowsTerminal` processes of detected console hosts (`conhost`, `openconsole`), avoiding the previous "add all terminals" broad fallback.
- **Scoring System**: Implemented a weighted priority system in `GetVisibleWindowsForPids`:
    - **100 pts**: Exact PID tree match + Title Hint match.
    - **50 pts**: PID tree match only (e.g., the CLI process itself).
    - **30 pts**: Title Hint match on a generic terminal process (fallback if tree linking fails).
- **Title Disambiguation**: Added `CalculateTitleScore` to resolve conflicts between similar titles (e.g., "omni" vs "omni-gemini-cli"). It favors shorter titles when the hint is a perfect match, preventing the Hub from targeting the wrong session when multiple are active.

### 2. Intelligent Monitor Movement (`ProcessService.cs`)
- **Proportional Mapping**: Refined `MoveHwndProportional` to map window positions using ratios relative to the work area (respecting taskbars).
- **Fixed Size & Clamping**: Windows now maintain their pixel size during movement (unless they exceed target bounds). Implemented clamping to ensure windows are pushed inside the target monitor's bounds if they would otherwise clip.
- **Position Memory**: Added a `_lastPositions` concurrent dictionary to track `(hWnd, hMonitor)` coordinates. Toggling a window back to a previous monitor now restores its exact relative position on that monitor.

### 3. Android Screen Persistence (`CustomKeyboard.kt`)
- **KeepScreenOn Utility**: Implemented a reusable `KeepScreenOn` composable using `DisposableEffect`.
- **Vertical Mode Integration**: Integrated this into the `CustomKeyboard` component, ensuring the phone screen stays active while the fullscreen landscape/vertical keyboard is in use.

### 4. Visibility & Logging
- **Hub UI Logs**: Enhanced `RpcApiHub` and `AiCliService` to log both the PID and the Workspace name for every remote command (Focus, Toggle Mon, Special Keys).
- **Dispatcher Trace**: Updated `CommandDispatcher` to log the exact payload being processed for monitor moves.

## Key Decisions

- **PID over Title**: Decided to strictly prioritize PID tree matches in window resolution, using Title Hints only as a tie-breaker or secondary heuristic.
- **Pixel-Perfect Size**: Retained pixel size during monitor moves instead of proportional scaling to prevent terminal windows from becoming illegibly small or excessively large.

## Insights

- **Terminal Complexity**: Linking `conhost.exe` to `WindowsTerminal.exe` reliably requires checking the parent-child relationship in the process tree, as they often don't share a direct linear lineage in modern Windows builds.
- **WMI Cache**: The 10-second WMI discovery cache in `AiCliService` is critical for performance but must be invalidated manually (`_lastWmiDiscovery = DateTime.MinValue`) after process-killing operations to ensure UI responsiveness.
