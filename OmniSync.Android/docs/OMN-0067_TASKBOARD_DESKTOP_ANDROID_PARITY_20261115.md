## Architecture decisions / remaining caveats

1. The PC TaskBoard vault and core remain sole authority. Task edits, review verdicts, archive/restore and AI queue operations route through the authenticated Hub; local image staging is immutable-content attachment preparation only. The old Android local review resolver was removed.
2. **Hub and Android must be deployed together.** New Android Undo and visual-review calls need `taskboard.phone.restore` and `taskboard.phone.review.resolve` in production OmniHub. Until the Hub update is active, do not treat the newly built Android APK as live for those features.
3. Reviews display already-synced local media. After a successful PC verdict, the local round is hidden temporarily and refresh/Syncthing brings the new manifest. An offline review is staged with its original operation UUID. The review response note may link to newly staged images before Syncthing has copied the image bytes to the PC; the image becomes available after sync.
4. The last single-card PC-confirmed archive is undoable on Android; batch archive is deliberately multi-operation and does not promise atomic one-tap undo. Full desktop historical undo, filesystem rename/delete, and OS-native drag-out remain desktop-specific.
5. Automatic tests were kept minimal per operator preference: Android `assembleDebug`, TaskBoard-core `cargo check`, OmniHub `cargo check`. There is no physical-phone end-to-end review round-trip confirmation without a deployed Hub and connected Android device; acceptance must not claim a live deployment based on compilation alone.

## Release handoff

- TaskBoard core: compile/check in `D:/SSDProjects/Tools/TaskBoard`; rebuild/restart desktop with `scripts/Rebuild-TaskBoard.ps1` (30-second Postpone UI).
- OmniHub: stage **production embedded** image using `docs/OMNIHUB_PRODUCTION_BUILD.md` and `scripts/omnihub-stage-production.ps1`; never launch an unembedded plain release binary and never restart Hub as a side effect of cargo check. Activate only a verified image through its guarded production path.
- Android: `D:/SSDProjects/Omni/OmniSync.Android/app/build/outputs/apk/debug/app-debug.apk`; install using `build_and_deploy.py`/Hub OTA after Hub routes active, or `adb install -r` to a connected device. `adb devices` initially reported no connected device.
