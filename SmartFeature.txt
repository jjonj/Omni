# OmniSync Hub - Smart Home Integration Guide (SmartNora Edition)

This guide walks you through integrating your C# **Omni Hub** with **Google Home** using **Node-RED**. We use **SmartNora** as the bridge because it is reliable, free, and creates devices directly inside Node-RED without external configuration websites.

## Phase 1: Installation & Setup

#### 1. Install Node-RED on Windows
Since Omni Hub is running on Windows, we run Node-RED locally to minimize latency.
1.  Download and install **[Node.js](https://nodejs.org/)** (LTS version).
2.  Open PowerShell as Administrator and run:
    ```powershell
    npm install -g --unsafe-perm node-red
    ```
3.  Start it by typing `node-red` in PowerShell. It will now be running at `http://localhost:1880`.

#### 2. Install SmartNora Plugin
1.  Open Node-RED (`http://localhost:1880`).
2.  Click the Menu (top right) -> **Manage Palette**.
3.  Go to the **Install** tab.
4.  Search for `node-red-contrib-smartnora` and click **Install**.

#### 3. Connect Google Home to SmartNora
1.  In Node-RED, drag any SmartNora node (e.g., a **Switch**) onto the canvas just to initialize the config.
2.  Double-click it, click the **Pencil icon** next to "Config".
3.  Follow the prompt to **Login with Google**. Copy the Authorization Code provided and paste it back into Node-RED.
4.  Click **Add**, then click **Done**.
5.  **Important:** Click the red **Deploy** button in the top right corner.
6.  **On your phone:** Open the Google Home App.
7.  Tap **+** -> **Set up device** -> **Works with Google**.
8.  Search for **Smart Nora** and link your account.

## Phase 2: Building the Flows

To control Omni Hub, Node-RED sends HTTP POST requests to your local API.
**Crucial Rule:** Omni Hub requires the header `Content-Type: application/json`, otherwise it will reject the command (Error 415).

### Example 1: The Master Power Switch
*Goal: "Hey Google, turn off the Computer."*

1.  **SmartNora Switch Node:**
    *   Drag a SmartNora **Switch** node.
    *   Name: `Computer`.
    *   Topic: `computer_power`.
2.  **Standard Switch Node:**
    *   Connect it to the SmartNora node.
    *   Rule 1: `is true` (Represents "Turn On").
    *   Rule 2: `is false` (Represents "Turn Off").
3.  **The "Turn Off" Path (Change Node):**
    *   Connect a **Change Node** to the "is false" output.
    *   **Set** `msg.payload` (Type: **JSON**) to: `{"Minutes": 1}`
    *   **Set** `msg.headers` (Type: **JSON**) to: `{"Content-Type": "application/json"}`
4.  **The "Turn On" Path (Change Node):**
    *   Connect a **Change Node** to the "is true" output.
    *   **Set** `msg.payload` (Type: **JSON**) to: `{"Minutes": 0}` (Cancels shutdown).
    *   **Set** `msg.headers` (Type: **JSON**) to: `{"Content-Type": "application/json"}`
5.  **HTTP Request Node:**
    *   Connect both Change nodes to this one **HTTP Request** node.
    *   **Method:** `POST`
    *   **URL:** `http://localhost:5000/api/external/command?key=test_api_key&cmd=SCHEDULE_SHUTDOWN`

### Example 2: Volume Control
*Goal: "Hey Google, set PC volume to 50%."*

1.  **SmartNora Light Node:**
    *   We use a "Light" because Google supports "Brightness" (0-100%), which maps perfectly to Volume.
    *   Name: `PC Volume`.
2.  **Change Node:**
    *   **Set** `msg.payload` (Type: **JSONata**) to: `{"VolumePercentage": msg.payload.brightness}`
    *   **Set** `msg.headers` (Type: **JSON**) to: `{"Content-Type": "application/json"}`
3.  **HTTP Request Node:**
    *   **Method:** `POST`
    *   **URL:** `http://localhost:5000/api/external/command?key=test_api_key&cmd=SET_VOLUME`

## Phase 3: Full List of Available Commands

You can trigger any of these by changing the `cmd=` parameter in the URL and the JSON Payload in the Change node.

| Virtual Device (SmartNora) | Google Command       | Omni Hub Command (`cmd=`) | JSON Payload Needed                  |
| :------------------------- | :------------------- | :------------------------ | :----------------------------------- |
| **Switch**                 | "Turn on/off"        | `SCHEDULE_SHUTDOWN`       | `{"Minutes": 0}` (or 1 for off)      |
| **Light** (Brightness)     | "Set volume to X%"   | `SET_VOLUME`              | `{"VolumePercentage": X}`            |
| **Switch**                 | "Turn on/off Mute"   | `TOGGLE_MUTE`             | `{}`                                 |
| **Scene**                  | "Activate Gaming"    | `OPEN_ON_PC`              | `{"Exe": "Paint"}`   |
| **Switch**                 | "Turn off Screen"    | `INPUT_KEY_PRESS`         | `{"KeyCode": 173}` (Mute/Vol keys)   |

## Phase 4: The "Stretch Goal" (Hub Controlling Other Devices)

Since Node-RED is running locally, your **Omni Hub can control your whole house** by sending requests *back* to Node-RED.

1.  **In Node-RED:** Install nodes for your physical devices (e.g., `node-red-contrib-tp-link`, `node-red-contrib-hue`).
2.  **In Node-RED:** Drag an **"HTTP In"** node. Set it to `GET /control-lights`. Connect it to your device node.
3.  **In Omni Hub (C#):** When you want to turn off the lights, just call:
    ```csharp
    var client = new HttpClient();
    await client.GetAsync("http://localhost:1880/control-lights");
    ```
