✅ In text editor we want to hook into the select popup to add options like itallic *x* and bold **x**, see here 
In Android, that popup is called the **Selection Action Mode**.

There are two ways to approach this depending on what you want to achieve:
1.  **Internal:** Adding options that only appear when text is selected **inside your app**.
2.  **System-wide:** Making your app appear as an option when text is selected **in any app** (like how Google Translate or Map searches work).

---

### 1. Adding options inside your own app (TextView/EditText)
If you are using standard Android XML views, you use the `setCustomSelectionActionModeCallback` method.

#### Step 1: Create a menu resource
Create a file in `res/menu/custom_selection_menu.xml`:
```xml
<menu xmlns:android="http://schemas.android.com/apk/res/android">
    <item
        android:id="@+id/menu_summarize"
        android:title="Summarize"
        android:showAsAction="ifRoom" />
</menu>
```

#### Step 2: Implement the Callback in your Activity/Fragment
```kotlin
val textView = findViewById<TextView>(R.id.myTextView)

textView.customSelectionActionModeCallback = object : ActionMode.Callback {
    override fun onCreateActionMode(mode: ActionMode?, menu: Menu?): Boolean {
        // Inflate your custom menu into the selection menu
        mode?.menuInflater?.inflate(R.menu.custom_selection_menu, menu)
        return true
    }

    override fun onPrepareActionMode(mode: ActionMode?, menu: Menu?): Boolean {
        return false // Return false if nothing is changed
    }

    override fun onActionItemClicked(mode: ActionMode?, item: MenuItem?): Boolean {
        return when (item?.itemId) {
            R.id.menu_summarize -> {
                // Get the selected text
                val min = textView.selectionStart
                val max = textView.selectionEnd
                val selectedText = textView.text.substring(min, max)
                
                // Do something with the text
                Toast.makeText(applicationContext, "Summarizing: $selectedText", Toast.LENGTH_SHORT).show()
                
                mode?.finish() // Close the menu
                true
            }
            else -> false
        }
    }

    override fun onDestroyActionMode(mode: ActionMode?) {}
}
```

### 2. Adding options in Jetpack Compose
If you are using Jetpack Compose, you need to override the `TextToolbar`.

```kotlin
val clipboardManager = LocalClipboardManager.current
val textToolbar = LocalTextToolbar.current

CompositionLocalProvider(
    LocalTextToolbar provides CustomTextToolbar(textToolbar) { 
        // Logic for your custom button
    }
) {
    SelectionContainer {
        Text("Select me to see custom options")
    }
}
```
*(Note: Implementing a custom `TextToolbar` in Compose is slightly more boilerplate-heavy as you have to wrap the existing system toolbar and add your items to the list of `ActionCallback`.)*

### 3. Adding your app to the "System" Menu (Everywhere)
If you want your app to show up when a user selects text in **Chrome, WhatsApp, or any other app**, you use an **Intent Filter** in your `AndroidManifest.xml`.

Android provides a specific action for this called `PROCESS_TEXT`.

#### Step 1: Update AndroidManifest.xml
```xml
<activity android:name=".ProcessTextActivity" android:label="My App Option">
    <intent-filter>
        <action android:name="android.intent.action.PROCESS_TEXT" />
        <category android:name="android.intent.category.DEFAULT" />
        <data android:mimeType="text/plain" />
    </intent-filter>
</activity>
```

#### Step 2: Handle the text in that Activity
When the user clicks your app name in that menu, your activity will open (often as a small dialog or transparent window).
```kotlin
override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)

    val selectedText = intent.getCharSequenceExtra(Intent.EXTRA_PROCESS_TEXT)
    val isReadOnly = intent.getBooleanExtra(Intent.EXTRA_PROCESS_TEXT_READONLY, false)

    // Process the text...

    // If you want to replace the text (only works in EditTexts):
    val resultIntent = Intent()
    resultIntent.putExtra(Intent.EXTRA_PROCESS_TEXT, "Replacement Text")
    setResult(RESULT_OK, resultIntent)
    finish()
}
```

### Summary
*   **`setCustomSelectionActionModeCallback`**: Use this to add "In-App" features (like "Apply Bold" or "Send to Internal Database").
*   **`PROCESS_TEXT` Intent**: Use this to make your app a tool for the entire OS (like a "Dictionary" or "Translator" app).
