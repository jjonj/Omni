# TFT Test Scripts

Tests and debugging utilities for Teamfight Tactics integration.

| File | Description |
| :--- | :--- |
| `test_tft_logic.js` | Core logic for unit selection and trait calculations. |
| `test_team_planner_code.js` | Validates encoding and decoding of team composition strings. |
| `test_rune_solver.js` | Tests the logic for recommending optimal runes. |
| `test_score_penalty.js` | Verifies scoring math for team evaluations. |
| `debug_tft_count.js` | Debugs unit count discrepancies in the UI. |
| `debug_bronze.js` | Specific test case for bronze-tier unit logic. |
| `debug_level4.js` | Specific test case for Level 4 shop odds/logic. |
