Here is the guide to implementing external access with a "Local First, WAN Fallback" strategy and dual-target WOL, keeping `85.80.233.70` as the default without requiring initial setup.

### 1. Update Configuration (`AppConfig.kt`)
Add a field for the WAN IP with your specific default value. This ensures it works out-of-the-box but allows changes later if your IP changes.

**Snippet:**
```kotlin
data class AppConfig(
    // ... existing fields ...
    var hubUrl: String = "http://10.0.0.37:5000/signalrhub", // Keep local as primary
    var wanIp: String = "85.80.233.70", // Hardcoded default public IP
    // ...
)
```

### 2. Implement "Local First, Remote Failover" (`SignalRClient.kt`)
Modify `startConnection` to attempt the local connection first. If that fails (timeout or error), automatically attempt to construct the URL using the WAN IP.

**Snippet:**
```kotlin
    fun startConnection() {
        _connectionState.value = "Connecting..."
        
        // 1. Define Local and Remote URLs
        val localUrl = mainViewModel.appConfig.hubUrl
        val remoteUrl = "http://${mainViewModel.appConfig.wanIp}:5000/signalrhub"

        // 2. Try Local First
        buildAndStartConnection(localUrl) { error ->
            // 3. Failure Callback: If local fails, try Remote
            mainViewModel.addLog("Local connection failed, trying Remote: $remoteUrl", LogType.WARNING)
            buildAndStartConnection(remoteUrl) { remoteError ->
                // Both failed
                _connectionState.value = "Disconnected (All attempts failed)"
                mainViewModel.setConnected(false)
            }
        }
    }

    private fun buildAndStartConnection(url: String, onFailure: (Throwable?) -> Unit) {
        hubConnection = HubConnectionBuilder.create(url).build()
        // ... register handlers here ...

        hubConnection?.start()
            ?.doOnComplete {
                onConnected()
                mainViewModel.addLog("Connected to: $url", LogType.SUCCESS)
            }
            ?.doOnError { error ->
                onFailure(error)
            }
            ?.subscribe()
    }
```

### 3. Dual-Broadcast Wake-on-LAN (`MainViewModel.kt`)
Update `sendWakeOnLan` to send the magic packet twice: once to the local broadcast address (`10.0.0.255`) and once to the WAN IP (`85.80.233.70`). This ensures the PC wakes up regardless of where your phone is, with zero user configuration.

**Snippet:**
```kotlin
    fun sendWakeOnLan(macAddress: String) {
        val wanIp = appConfig.wanIp
        
        viewModelScope.launch(Dispatchers.IO) {
            try {
                // 1. Prepare Packet
                val macBytes = getMacBytes(macAddress)
                val bytes = ByteArray(6 + 16 * macBytes.size)
                // ... (fill byte array logic) ...

                val socket = DatagramSocket()

                // 2. Send Local Broadcast (Inside Network)
                val localAddress = InetAddress.getByName("10.0.0.255")
                val localPacket = DatagramPacket(bytes, bytes.size, localAddress, 9)
                socket.send(localPacket)

                // 3. Send Remote Unicast (Outside Network)
                val remoteAddress = InetAddress.getByName(wanIp)
                val remotePacket = DatagramPacket(bytes, bytes.size, remoteAddress, 9)
                socket.send(remotePacket)

                socket.close()
                addLog("WOL sent to Local & $wanIp", LogType.SUCCESS)
            } catch (e: Exception) {
                addLog("WOL Failed: ${e.message}", LogType.ERROR)
            }
        }
    }
```

### 4. Add WAN Override to UI (`SettingsScreen.kt`)
Add a simple text field in Settings so you can update the IP if `85.80.233.70` ever changes, without recompiling the app.

**Snippet:**
```kotlin

    var wanIp by remember { mutableStateOf(appConfig.wanIp) }

    OutlinedTextField(
        value = wanIp,
        onValueChange = { wanIp = it },
        label = { Text("WAN IP (Public)") },
        modifier = Modifier.fillMaxWidth()
    )

    // Update the Save Button onClick:
    Button(
        onClick = {
            appConfig.hubUrl = hubUrl
            appConfig.apiKey = apiKey
            appConfig.wanIp = wanIp // Save new WAN IP
            mainViewModel.saveAppConfig()

    }
```
